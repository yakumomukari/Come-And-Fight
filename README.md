# Come-And-Fight

Playable modes include single-player and LAN Host/Client online play. Online actions are resolved only by the Host and both peers play the same authoritative result locally.

Windows builds default to a resizable 1280 × 720 window for side-by-side Host/Client testing.

See [Docs/NETWORK.md](Docs/NETWORK.md) for architecture, local testing, limitations, and next steps.
